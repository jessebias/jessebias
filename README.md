## Verta

**[verta.xyz](https://verta.xyz)** · [verta-hq](https://github.com/verta-hq) · [Solana program](https://github.com/verta-hq/programs)

Vertical micro-drama streaming for iOS, Android and web. Consumers watch short, serialized episodes; creators and studios publish through Verta Studio and are paid out on-chain. Currently in closed beta.

- Coin + VIP economy with USDC settlement on Solana; every user transaction is gas-sponsored, so viewers need zero SOL
- Creator revenue-share launchpad with on-chain royalty splits
- Verta Studio: self-serve publishing for creators and partner studios, with an ops review pipeline
- Personalized For You feed, weekly creator leaderboard and an internal admin dashboard

**Stack:** NestJS · Prisma · PostgreSQL (Supabase) · React 19 + Vite + Tailwind · Flutter · Solana (Anchor / Rust) · Privy · Mux · Next.js
